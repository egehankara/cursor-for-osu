# Security Policy

## Supported Versions

Only the latest version on the `master` branch receives security fixes.

## Reporting a Vulnerability

Please do **not** open a public issue for security problems.

Report vulnerabilities privately via GitHub's
[private vulnerability reporting](https://github.com/egehankara/cursor-for-osu/security/advisories/new).

I'll try to acknowledge reports within a few days and keep you updated on the fix.
